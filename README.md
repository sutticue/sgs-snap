# SGS Snap

copy คะแนนจาก Google Sheets แล้ววางลงหน้า "บันทึกผลการเรียน" ของ SGS ได้ทีเดียวหลายช่อง

developed by โปรเจคเด็กดื้อ

## ใช้งาน

แจกไฟล์ **`sgs-snap.html`** ไฟล์เดียว — ในหน้ามีปุ่มให้ลากขึ้นแถบ Bookmark 2 แบบ

| ปุ่ม | ทำงานยังไง |
|---|---|
| **SGS Snap** | วางปุ๊บ คะแนนขึ้นเต็มหน้าทันที · SGS บันทึกเบื้องหลัง · refresh เช็คเอง |
| **SGS Snap Safe** | กรอกทีละช่อง รอ SGS ตอบก่อนไปต่อ · เขียว = รับแล้ว · แดง = ไม่รับ |

1. **ติดตั้ง (ครั้งเดียว)** — `Ctrl+Shift+B` เปิดแถบ Bookmark → **ลาก** ปุ่มขึ้นแถบ (ห้ามคลิก)
2. **ใช้งาน** — เปิดหน้า SGS → คลิกปุ่มบนแถบ (มุมขวาล่างขึ้น `[v8 · Snap] พร้อมแล้ว`) → ติ๊กคอลัมน์ →
   copy จาก Sheets → คลิกช่องแรก → `Ctrl+V` → ตกลง → เช็คผล

## หลักการ

- bookmarklet = bookmark ที่เก็บโค้ดแทน URL — คลิกแล้วโค้ดรันบนหน้าที่เปิดอยู่
- ดักการวาง → แยกข้อมูลจาก Sheets (Tab = คอลัมน์ · ขึ้นบรรทัด = แถว) → จับคู่กับช่องตามชื่อ id ของ SGS
  (`...TableControlRepeater_ctl{แถว}_{คอลัมน์}`)
- ตรวจคะแนนเต็มจาก `onchange="CheckValue(..., 'S10', '<เต็ม>', ...)"` ของแต่ละช่อง — ผิดช่องเดียวไม่กรอกทั้งชุด
- ใส่ค่า + `dispatchEvent('change')` ให้ SGS บันทึกเองผ่าน flow เดิม (`CheckValue → PageMethods.SaveMe → GetGr → MyCallBack1`)
- **Safe** ดัก `MyCallBack1` / `MyError` / `alert` ชั่วคราวเพื่อรู้ผลทีละช่อง แล้วคืนของเดิม
  — ต้องรอทีละช่องเพราะ callback ของ SGS เก็บ "ช่องที่กำลังบันทึก" ไว้ใน global ร่วมกัน
- **Snap** ใส่ทุกช่องในรอบเดียว — `SaveMe` รับค่าเป็น argument จึงบันทึกถูกช่อง
  แต่ช่องรวม/เกรดบนจออาจไม่อัปเดตจนกว่าจะ refresh

## ข้อจำกัด

- รองรับเฉพาะหน้าที่มีช่อง `S10`–`S18`, `Final`, `ReGr`, `RepeatGr`, `Remark` (หน้า "หลังกลางภาค")
- จับคู่นักเรียนตามลำดับแถว ไม่ใช่เลขประจำตัว — ลำดับใน Sheets ต้องตรงกับ SGS
- คอลัมน์ที่ยังไม่ติ๊กเปิดจะถูกข้าม (เหมือนปุ่ม Enter ของ SGS)
- ใช้ได้ทีละปุ่มต่อหน้า — จะสลับแบบต้อง refresh ก่อน

## พัฒนา

```bash
node source/test.js    # เทส logic ทั้งสองแบบกับหน้า SGS จำลอง
node source/build.js   # สร้าง sgs-snap.html ใหม่จาก source/
```

- `source/sgs-paste.js` — โค้ดหลักชุดเดียว (`INSTANT` สลับแบบ · แก้ `VERSION` ทุกครั้งที่แก้โค้ด)
- `source/page.html` — หน้าติดตั้ง (`javascript:INSTANT` / `javascript:SAFE` / `{{VERSION}}` ถูกแทนตอน build)
- แก้แล้วต้องรัน `build.js` และผู้ใช้ต้องลากปุ่มใหม่ (ปุ่มที่ลากไปแล้วไม่อัปเดตตาม)
