SGS ช้าไหม

วิธีเช็คว่าตอนนี้ server ของ SGS หนักแค่ไหน ก่อนตัดสินใจกรอกคะแนนหรือรอไปกรอกช่วงอื่น

ทำไมต้องเช็คทางอ้อม

ตัวเลขโหลดของ server (CPU, จำนวนคนใช้) มีแค่ทีมดูแล SGS ที่เห็น สิ่งที่เราวัดได้คือ SGS ตอบเร็วแค่ไหน — ถ้าตอบช้า แปลว่า server กำลังหนัก

วิธีที่ 1 · ดูเวลาตอบใน browser — แม่นที่สุด

  1. เปิดหน้า "บันทึกผลการเรียน" ใน SGS แล้วกด F12 (Mac: Cmd+Option+I) จะมีแผงเครื่องมือเปิดขึ้นข้างหน้าเว็บ
  2. เลือกแท็บ Network แล้วพิมพ์ SaveMe ในช่อง Filter
  3. กรอกหรือวางคะแนนตามปกติ ทุกช่องที่บันทึกจะมีบรรทัด SaveMe โผล่ขึ้นมา 1 บรรทัด
  4. ดูคอลัมน์ Time ของแต่ละบรรทัด แล้วเทียบกับตารางด้านล่าง
Timeความหมาย
ต่ำกว่า 0.5 วินาทีปกติ กรอกได้เลย
1 – 3 วินาทีเริ่มหนัก ยังกรอกได้ แต่ควรใช้ SGS Snap Safe เพื่อรู้ผลทุกช่อง
เกิน 5 วินาทีหนักมาก ควรรอไปกรอกช่วงอื่น
(failed) · 500 · 502 · 504server ล่มหรือรับไม่ไหว — หยุดกด refresh รัวๆ แล้วรอ 5–10 นาที

ค่าในคอลัมน์ Time แสดงเป็น ms (มิลลิวินาที) — 1,000 ms = 1 วินาที

วิธีที่ 2 · สังเกตจาก SGS Snap Safe

  • ช่องเปลี่ยนจากเหลืองเป็นเขียวเร็วแค่ไหน คือความเร็วที่ SGS ตอบ
  • ถ้าไล่ไปช้าๆ ทีละช่องเห็นได้ชัด แปลว่า server หนัก
  • ถ้ากล่องขึ้น "server ไม่ตอบ 15 วินาที" แปลว่าค้างหรือล่ม

วิธีที่ 3 · ถามคนอื่น

กลุ่ม Facebook หรือ LINE ของครูมักมีคนโพสต์ก่อนเสมอเมื่อ SGS ล่ม — ถ้าหลายคนเจอพร้อมกัน แปลว่าเป็นที่ server ไม่ใช่เครื่องเรา

ช่วงที่มักจะหนัก

  • ใกล้วันกำหนดส่งคะแนน — ครูทั้งระบบเข้าพร้อมกัน
  • เวลาทำงาน โดยเฉพาะช่วงบ่ายและหัวค่ำ
  • ช่วงที่คนน้อยกว่า: ดึก (หลัง 4 ทุ่ม) หรือเช้าตรู่ (ก่อน 7 โมง) — แต่บางคืนระบบอาจปิดปรับปรุง
  • กรอกเสร็จก่อนกำหนดส่ง 1–2 สัปดาห์ จะสบายที่สุด

สิ่งที่ไม่ควรทำ

  • กด refresh รัวๆ ตอน SGS ล่ม — แต่ละครั้งคือคำขอใหม่ที่ไปเพิ่มภาระ
  • ตั้งโปรแกรมยิงเช็ค SGS อัตโนมัติ — เป็นการส่งคำขอไป server ราชการโดยไม่ได้ใช้งานจริง และเพิ่มภาระตอนที่หนักอยู่แล้ว
